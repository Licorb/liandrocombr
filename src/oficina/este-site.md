E não é que este site também é uma oficina? Muita experimentação, vibe-coding impulsionado por alguns modelos diferentes de IA, vai e vem conceitual até chegar no formato atual.  

<br>

O site/repositório é feito utilizando a ferramenta <a href="https://www.11ty.dev/" target="_blank">Eleventy</a>, com SSL e Firewall da <a href="https://www.cloudflare.com/pt-br/" target="_blank">Cloudeflare</a>, Redirecionamento DNS na <a href="https://vercel.com/" target="_blank">Vercel e Repositório e versionamento no <a href="https://github.com/" target="_blank">Github</a>, apontando pra um registro no <a href="https://registro.br/" target="_blank">Registro.br</a>. O custo de tudo? **30 reais por ano**, que é o do domínio. Toda estrutura é dependente de uma rede gratuita.

<br>

É um projeto interessante onde pude e posso lançar mão de meus conhecimentos técnicos junto com as ferramentas que temos disponíveis hoje em dia para dar concretude a algo que descobri há pouco que sempre quis ter.
